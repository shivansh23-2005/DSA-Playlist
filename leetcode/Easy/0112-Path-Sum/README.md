# Path Sum

**Difficulty:** Easy  
**Topics:** Tree, Depth-First Search, Breadth-First Search, Binary Tree  
**LeetCode URL:** [Path Sum](https://leetcode.com/problems/path-sum/)

## Problem Description

<p>Given the <code>root</code> of a binary tree and an integer <code>targetSum</code>, return <code>true</code> if the tree has a <strong>root-to-leaf</strong> path such that adding up all the values along the path equals <code>targetSum</code>.</p>

<p>A <strong>leaf</strong> is a node with no children.</p>

<p>&nbsp;</p>

## Solution

```java
// LeetCode Problem: Path Sum
// Link: https://leetcode.com/problems/path-sum/
// Difficulty: Easy
// Language: java

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if(root==null) return false;
      
        return solve(root,0,targetSum);  
    }
    public boolean solve(TreeNode root,int csum,int target)
    {
        if(root==null) return false;
        csum+=root.val;
        if(root.left==null && root.right==null)
        {
            if(csum==target)
            {
                return true;
            }
            else
            {
                return false;
            }
        }
       return solve(root.left,csum,target) ||solve(root.right,csum,target);
    }
}
```
